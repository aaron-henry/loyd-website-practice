                                                                                                                                                                    # loyd-website-practice
Create a login page that matches the design of the existing website.

### Requirements

1. Create a new file called `login.html`.

2. Add a **Login** link to the navigation bar in `index.html`.

3. The Login link should open `login.html`.

4. The login form should contain:

- Email address field
- Password field
- Show password option
- Remember me checkbox
- Forgot password link
- Login button
- Link to create an account

5. Add a link or button that takes the user back to the homepage.

6. Style the login page using `style.css`.

7. The page must work properly on desktop and mobile screens.

8. Use HTML form validation:

- Email must be required
- Password must be required
- Email field must use `type="email"`
- Password field must use `type="password"`



                                                                                                                                                                    # Assignment: Rebrand the Website as Morrow Goods

Rename the website from **Vanta Supply** to **Morrow Goods** and create a completely new homepage hero section.

## Tasks

### 1. Update the brand name

Replace every visible reference to:

`Vanta Supply`

with:

`Morrow Goods`

Check both the homepage and login page.

### 2. Update page titles

Update the `<title>` element in:

- `index.html`
- `login.html`

Use suitable titles such as:

- `Morrow Goods | Home`
- `Morrow Goods | Login`

### 3. Update the navigation bar

The navigation should contain:

- **Morrow Goods logo**
- Shop
- Our Story
- Login

The **Morrow Goods logo** should act as the Home link and open `index.html`.

The Login link should open `login.html`.

The Shop and Our Story links may temporarily point to sections on the homepage until their pages are created.

### 4. Create a new split-layout hero section

Replace the current homepage hero with a completely new split-layout design.

The hero must have two sides.

#### Left side

Include:

- New Season Collection label
- Main heading
- Short description
- Shop Collection button
- Our Story button

#### Right side

Include:

- A large lifestyle or product image
- Suitable descriptive `alt` text
- Rounded image corners

### 5. Hero heading

Use this heading:

> Simple pieces for everyday living.

### 6. Hero description

Use this description:

> Explore thoughtfully selected clothing and accessories designed for comfort, quality and effortless style.

### 7. Hero buttons

Add the following buttons:

- **Shop Collection**
- **Our Story**

The buttons should have hover effects and should match the new Morrow Goods branding.

### 8. Responsive design

Make the hero responsive.

On smaller screens:

- The image and content should appear in one column.
- The image should remain clear and properly sized.
- The buttons should wrap or stack correctly.
- Text must not overflow outside the screen.
- The navigation must remain usable.
- There should be no horizontal scrolling.

### 9. Brand consistency

The homepage and login page should use consistent:

- Brand name
- Colours
- Typography
- Buttons
- Spacing
- Navigation styling

### 10. Test the website

Before submitting, test:

- The logo Home link
- The Login link
- The back-to-home link on the login page
- Desktop layout
- Tablet layout
- Mobile layout
- Image loading
- Text readability
